直接提问

    这些数字怎么算？

    服务支持余额接口时，每分钟刷新。服务未提供余额时只显示本机用量，不估算剩余充值。

    调用次数仅统计本机网页模型请求，包含规划、复核和重试。保守计提按已记录用量计算，不是服务商实际扣款；保留额度包含旧挂账与在途请求，不会再次从余额中扣除。

    已结算用量 — tokens。查询账户不会生成模型回答。

    先了解密钥安全

    API Token 等同账户密码。泄露后，他人可能使用你的额度并产生费用。

    • 只在你信任的部署电脑上填写；不要发到聊天、截图或公开仓库。
    • 新保存的 Token 会在服务端加密存储，前端不会回显原值。
    • 加密不替代主机安全；能控制部署电脑的人仍可能访问密钥。

    仅发送到部署电脑校验并保存。校验读取余额，不调用付费模型。
