# 运行手册

## 首次安装

macOS 桌面用户在 Finder 解压并双击项目根目录的启动文件。首次下载依赖需要网络，导入资料需要可写目录和磁盘空间。请至少预留 3 GB。项目使用 Python 3.12 和 PostgreSQL 16。安装脚本优先使用已安装的工具，也可以为 Intel 或 Apple Silicon 获取工具。

请从仓库根目录运行命令。需要为同一台 Mac 上的第二份安装避开端口时，可以这样启动：

```bash
./启动方舟档案.command --port 8010
```

## 模型和手机

在部署电脑上打开工作台，进入模型管理。选择服务商或兼容中转，输入自己账号的 Key，确认模型后保存。兼容站需要 HTTPS 根地址和支持工具调用的模型。首次向模型提问会使用该账号的额度。

普通入口只监听回环地址。局域网入口额外监听当前 Wi-Fi 私有地址，切换模式会重启后台服务，进行中的任务会阻止停止。切换 Wi-Fi 后重新启动局域网入口以获取新网址。手机浏览器可切换电脑已配置的模型；手机与电脑浏览器各有自己的草稿和对话目录。

## 状态、停止和备份

```bash
.venv/bin/python -m scripts.launch_workbench --status
.venv/bin/python -m scripts.launch_workbench --stop
.venv/bin/python -m scripts.dev_postgres stop
```

如使用自定义网页端口，给前两条命令加上相同的 `--port`。后台程序通过 macOS LaunchAgent 启动，日志位于 `~/Library/Logs/ArknightsWorkbench/<端口>.log`。停止工作台会卸载对应的登录启动项。数据库在本机项目目录下运行。

保留原文件夹可继续使用原安装。迁移前先停止网页和数据库，备份项目下的 `.local/` 和用户目录的 `~/.config/arknights-agent/master.key`，用私密介质分别妥善保管。前者包含数据库、模型连接密文、任务记录和用量账本。浏览器本地保存的草稿与目录需保留对应浏览器数据。遇到端口占用时请改端口或停止原服务。

## 开发回归

安装 uv，准备一套专用 PostgreSQL 16 数据库后执行：

```bash
uv sync --frozen
export ARK_TEST_DATABASE_URL='postgresql+psycopg://localhost/arknights_test'
uv run python -m pytest -m 'not live'
```

发布包恢复验收会在 CI 的空数据库执行迁移、导入资料、核对温蒂公招引用并验证再次启动。开发测试使用临时账本和模拟模型。提交问题前请删除日志里的私密内容。
